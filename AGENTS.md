# Repository guidance

Before changing repository files, read `.github/copilot-instructions.md`.
For feature requests, bug fixes, and delivery, follow
`.github/skills/development-workflow/SKILL.md`; the skill configuration below
does not replace its validation, publication, merge, or completion gates.

## Agent skills

### Issue tracker

Track issues and specs in GitHub Issues for `laqieer/fireemblem8-expansion`.
Before reading or publishing tickets, read `docs/agents/issue-tracker.md`.

### Triage labels

Use the five default triage labels. Before applying a triage role, read
`docs/agents/triage-labels.md`.

### Domain docs

Use single-context domain docs: root `GLOSSARY.md` and `docs/adr/`.
Before exploring domain terminology or architectural decisions, read
`docs/agents/domain.md`.
