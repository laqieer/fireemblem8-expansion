# Triage labels

The engineering skills use five canonical triage roles. Map each role to the
label below when reading or updating GitHub Issues.

| Canonical role | Label in our tracker | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Maintainer needs to evaluate this issue |
| `needs-info` | `needs-info` | Waiting on reporter for more information |
| `ready-for-agent` | `ready-for-agent` | Fully specified, ready for an autonomous agent |
| `ready-for-human` | `ready-for-human` | Requires human implementation |
| `wontfix` | `wontfix` | Will not be actioned |

When a skill mentions a role, use its corresponding tracker label. These
labels describe triage readiness; the repository development workflow remains
authoritative for implementation, manual-testing holds, merge, and closure.

Edit the "Label in our tracker" column to use an existing vocabulary instead.
